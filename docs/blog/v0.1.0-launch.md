# Introducing PEPA v0.1.0 — The Open-Source Platform Engineering & Pipeline Automator Built for GitOps

> *Delivery without pain, GitOps with joy.*

Today we're excited to announce **PEPA v0.1.0** — the first general availability release of our open-source Platform Engineering & Pipeline Automator.

PEPA is built for platform engineering teams who want a self-hosted, extensible, and AI-powered alternative to SaaS-only developer portals like Backstage, Port, and Cortex.

---

## What is PEPA?

PEPA (Platform Engineering & Pipeline Automator) is an open-source platform that unifies:

- **Service Catalog** — register and browse all services with ownership, health, and scorecards
- **GitOps Deployments** — FluxCD and ArgoCD integration with drift detection and auto-heal
- **CI/CD Pipelines** — visual pipeline builder with blueprints
- **Workflow Automation** — DAG-based engine with visual designer
- **Infrastructure Management** — Kubernetes, Docker, Proxmox VE
- **Plugin Ecosystem** — 10 built-in plugins, Go SDK for custom integrations
- **AI Assistant** — context-aware chat with RAG framework
- **Security** — Vault integration, RBAC, audit logging

---

## Why We Built PEPA

Platform engineering teams face a common set of challenges:

1. **Tool sprawl** — services spread across Git, CI/CD, monitoring, secrets, and cloud providers with no unified view
2. **Manual deployments** — no GitOps, no approval gates, no drift detection
3. **No self-service** — developers wait for platform teams to provision resources
4. **SaaS lock-in** — commercial IDPs require sending your data to third-party clouds

PEPA solves all of these with a single, self-hosted platform that gives developers self-service access while maintaining guardrails.

---

## Key Differentiators

### 1. Plugin-First Architecture

Every integration is a plugin with **process isolation** via gRPC. Plugins can be written in Go, Python, TypeScript, or Rust. No more in-process plugin crashes taking down your entire portal.

### 2. GitOps Orchestration Built-In

PEPA doesn't just catalog services — it orchestrates deployments. Native FluxCD and ArgoCD integration with drift detection, auto-heal, and multi-environment promotion.

### 3. Visual Workflow Engine

Build complex deployment workflows with a visual DAG designer. Add approval gates, conditional steps, rollback triggers, and parallel execution — all without writing code.

### 4. AI-Native

Built-in RAG (Retrieval-Augmented Generation) framework with LLM-agnostic support. Connect to OpenAI, local models, or any compatible API. The AI assistant can query your catalog, analyze deployments, and recommend actions.

### 5. Truly Self-Hosted

Designed for air-gapped environments. No SaaS dependencies. Your data stays on your infrastructure. Deploy with Docker Compose or Helm on Kubernetes.

## Getting Started

### Docker Compose (5 minutes)

```bash
git clone https://github.com/your-username/pepa.git && cd pepa
make docker-up
# Open http://localhost:3000
```

### CLI Install

```bash
curl -fsSL https://github.com/your-username/pepa/releases | sh
pepa install --compose
```

### Kubernetes (Helm)

```bash
helm install pepa oci://docker.io/charts/pepa --namespace pepa --create-namespace
```
